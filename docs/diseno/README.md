# Diseños de referencia de PulsePass

Esta carpeta contiene las 32 imágenes PNG indexadas en la sección 9.0 del PRD de Frontend adjunto al proyecto. Se extrajeron de las páginas ilustradas del PDF para que el equipo pueda consultar y versionar las referencias junto con el código.

- Las imágenes de escritorio y móvil conservan los nombres definidos por el PRD.
- `CatalogoOscuro.png` y `DetalleOscuro.png` son referencias de modo oscuro.
- `Sistema.png` contiene los tokens, tipografía, botones, badges y campos.
- Las imágenes `Movil*.png` sirven como referencia para los anchos pequeños.

El PRD original está en `docs/PRD_PulsePass_Frontend_React_TypeScript_Tailwind.pdf`.
